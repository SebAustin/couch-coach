# Couch Coach

A living-room fitness coach for Fire TV. Your phone becomes the camera: pose estimation runs on the phone, the Fire TV draws your live skeleton, counts reps and scores your form, and an AI coach on AWS speaks feedback after each set and remembers each member of the household.

Built for **Build, Ship, Shape: Amazon Developer Hackathon** (Fire TV track, AWS Builder and Open Source mini challenges). Setup instructions land here as the build progresses; see `PLAN.md` and `STATUS.md`.

The rep counting and form scoring live in the separate open-source library [pose-reps](https://github.com/SebAustin/pose-reps).

`apps/tv` is derived from [AmazonAppDev/react-native-multi-tv-app-sample](https://github.com/AmazonAppDev/react-native-multi-tv-app-sample) (MIT No Attribution).
